# Portfolio Ferika Syavina Putri

Website portfolio personal menggunakan:
- HTML5
- CSS3
- JavaScript

## Cara menjalankan
1. Extract folder/project.
2. Buka folder di VS Code.
3. Buka `index.html`.
4. Klik kanan -> Open with Live Server (jika extension Live Server sudah terpasang).

## Sebelum dipublikasikan
- Ganti `Perguruan Tinggi — Indonesia` dengan nama kampus.
- Ganti link GitHub `https://github.com/username/` dengan akun GitHub asli.
- Masukkan file CV dengan nama `CV-Ferika-Syavina-Putri.pdf`.
- Jika ingin menampilkan foto, bagian `profile-placeholder` pada index.html bisa diganti dengan `<img>`.
- Tambahkan link GitHub/demo pada masing-masing project jika sudah tersedia.
